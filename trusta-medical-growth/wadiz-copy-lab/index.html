20 design DNA patterns

첨부 캡처를 복사하지 않고, 구조만 재사용했습니다

PATTERN 01

상승선 + 큰 종착 숫자

시간축과 상승 방향을 한 번에 읽게 만드는 성장 증거형.

PATTERN 02

인물 콜라주 + 시스템 맵

사람의 권위와 기술 구조를 좌우 대비하는 에디토리얼형.

PATTERN 03

Before / After 분할

평범한 결과와 설계된 결과를 같은 크기로 비교하는 변화형.

PATTERN 04

실제 노드 그래프

복잡한 관계가 연결되어 있음을 과장 없이 보여주는 구조 증거형.

PATTERN 05

중앙 허브 + 궤도

여러 지식 원천이 하나의 검증 중심으로 모이는 생태계형.

PATTERN 06

SNS 결과 콜라주

여러 채널의 실제 화면을 겹쳐 성과 범위를 보여주는 증거 갤러리형.

PATTERN 07

3개 핵심 지표

서로 다른 데이터 형태를 같은 높이로 정렬하는 트리플 메트릭형.

PATTERN 08

뉴스 스택 + 이중 차트

문제의 사회적 맥락과 수치를 위아래로 연결하는 위기 증거형.

PATTERN 09

번호 카드 모자이크

핵심 구성요소를 3+2 리듬으로 한눈에 읽게 만드는 특징 요약형.

PATTERN 10

고민 말풍선

고객 머릿속 문장을 시각화해 문제 인식을 빠르게 만드는 공감형.

PATTERN 11

X → Check 비교

기존 방식과 새 방식을 단순한 기호로 구분하는 선택형.

PATTERN 12

2+3 포인트 그리드

가장 중요한 두 개를 크게, 보조 세 개를 작게 두는 우선순위형.

PATTERN 13

시스템 고도화 루틴

스크린샷과 Step 목록, 완료 배너로 실행 가능성을 증명하는 미션형.

PATTERN 14

좌우 Mission 패널

두 개의 작업 목표와 결과 화면을 나란히 보여주는 실습형.

PATTERN 15

연결 계정 + 워크플로

서비스 연결 증거와 자동화 흐름을 두 화면으로 입증하는 기술형.

PATTERN 16

글·이미지·영상 단계

여러 산출물이 만들어지는 과정을 화면과 체크리스트로 보여주는 제작형.

PATTERN 17

롱폼 → 숏폼 변환

입력과 출력의 장면을 나란히 두어 재가공 가치를 보여주는 변환형.

PATTERN 18

원본 1개 → 채널 다수

하나의 소스가 플랫폼별 언어로 재탄생하는 옴니채널형.

PATTERN 19

운영 자동화 미션

리드 수집과 후속 행동을 단계별로 증명하는 운영형.

PATTERN 20

리소스 스택

매뉴얼·워크플로·프롬프트·코드를 한 시스템의 층으로 보여주는 제공물형.
