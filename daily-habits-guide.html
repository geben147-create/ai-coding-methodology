1. 역할 정의 — 누가 무엇을 하는가

딸 (87년생, 대표) 핵심 실무자 — 일의 90%

  • 동호회 대표 (고유번호증 명의)
  • 영수증 수집 총괄 — 매일 습관
  • 엑셀 기록 관리 (주 1회)
  • 통장/카드 내역 정리
  • 세무 신고 준비 (5월 종소세)
  • 회원 회비 수납 확인
  • 강사비 지급 + 원천징수
  • 건물 관리 업무 실행
  • 관리 업무 일지 작성 (월 1회)

아버지 (건물주) 서류 제공자

  • 임대차 계약 당사자 (갑)
  • 전대 동의서 서명
  • 수리비 승인 (50만 원 초과)
  • 건물 관련 영수증 딸에게 전달
  • 관리수수료 매월 이체
  • 세금계산서 발행 (필요 시)

동호회원 회비 납부자

  • 매월 회비 단체통장으로 이체
  • 현금 납부 시 확인서 서명
  • 총회 참석 (연 1회)
  • 그 외 할 일 거의 없음

회장 (명목) 최소 역할

  • 연 1회 총회 의장
  • 고유번호증 갱신 시 서명
  • 실제로 할 일 거의 없음

2. 매일 해야 할 습관 (Daily) — 1분이면 끝

가장 중요한 한 줄: "돈을 쓸 때마다 영수증을 받아라. 카드로 결제하라. 현금이면 간이영수증이라도 받아라."

딸 매일 4가지

#행동왜 해야 하나소요팁
1영수증 받기비용 인정의 유일한 증거10초"사업자용 현금영수증 끊어주세요" (고유번호 말하기)
2영수증 사진 찍기종이 영수증은 6개월이면 글씨 사라짐5초스마트폰 "영수증" 앨범에 저장
3카드 결제 우선카드 매출전표 = 적격증빙 자동 생성0초단체 전용 체크카드 사용
4영수증 뒤에 메모"이게 뭐였지?" 방지10초예: "연습실 간식", "악보 복사"
실전 예시 — 과일 사러 간 경우
상황: 동호회 연습 후 간식으로 과일 3만 원 구매

1. 마트에서 카드 결제 (단체 전용 카드)
2. 영수증 받기 → "사업자용 현금영수증 고유번호 ○○○-○○-○○○○○" 요청
3. 영수증 뒷면에 "동호회 연습 간식" 메모
4. 사진 찍어서 "영수증" 폴더에 저장
5. 주 1회 엑셀 입력 시 반영
→ 비용 항목: 회의비/간담회비 → 연간 약 36만 원 절세 기여

아버지 매일 할 일

딱 하나: 건물 관련으로 돈 쓰면 영수증 버리지 말고 딸에게 주기. 끝!

3. 매주 해야 할 일 (Weekly) — 일요일 30분

#행동담당소요방법
1영수증 정리 (한 주간 모은 것)딸10분월별 봉투에 분류
2엑셀 입력 (날짜/금액/항목/증빙)딸15분아래 엑셀 양식 참고
3통장 잔액 확인딸3분모바일뱅킹
4회비 입금 확인딸2분미입금자 리마인드
매주 일요일 루틴 ┌──────────────────────────────────────┐ │ 10분 영수증 정리 (사진+봉투 분류) │ │ 15분 엑셀 입력 │ │ 3분 통장 잔액 확인 │ │ 2분 회비 입금 체크 │ │ ──────────────────── │ │ 합계: 30분 │ └──────────────────────────────────────┘

4. 매월 해야 할 일 (Monthly) — 매월 1~5일, 약 2시간

딸 매월 체크리스트

#행동마감상세
1회비 수납 확인 + 독촉매월 5일회원별 입금 여부 체크, 미납자 문자
2강사비 지급 + 3.3% 원천징수매월 10일강사에게 이체 후 원천세 신고
3임대료 지급 (연습실)계약서 기준일아버지 계좌로 이체
4관리수수료 수령 확인매월 말아버지 → 단체통장 입금 확인
5교회 월세 수납 확인계약서 기준일교회 → 단체통장 입금 확인
6월간 수입/지출 정산표매월 5일엑셀에서 전월 합계 정리
7영수증 봉투 밀봉매월 5일"2026년 3월" 라벨 → 보관
8관리 업무 일지매월 말관리 위탁 계약 의무 (A4 1장)

아버지 / 교회 / 회원

역할할 일마감
아버지관리수수료 이체 (월세의 10%)매월 말
아버지수리 승인 (50만 초과 시)수시
아버지건물 영수증 딸에게 전달수시
교회월세 단체통장으로 이체계약 기준일
회원회비 단체통장으로 이체매월 5일

월간 자금 흐름도 (실제 숫자)

============ 수입 (IN) ============ 회원 회비 10명 x 22만 = 220만 원 ──┐ 교회 월세 = 28만 원 ──┤ 관리수수료 175만x10% = 17.5만 원 ──┤ ▼ ┌─────────────────┐ │ 단체 통장 입금 │ │ 월 265.5만 원 │ └────────┬────────┘ │ ============ 지출 (OUT) =========== │ ▼ 연습실 임대료 (→아버지) 50만 원 ◀──┤ 아버지 원임대료 송금 20만 원 ◀──┤ 강사비 (원천징수 포함) 80만 원 ◀──┤ 교재/악보/소모품 10만 원 ◀──┤ 간식/회의비 8만 원 ◀──┤ 교통비/주유비 10만 원 ◀──┤ 통신비 3만 원 ◀──┤ 사무용품/인쇄 5만 원 ◀──┤ 행사비 적립 10만 원 ◀──┤ 수리비 (평균) 5만 원 ◀──┘ ───────────────────────────── 지출 합계 201만 원 ============ 결과 ================= 월 잔여: 265.5 - 201 = 64.5만 원 (통장에 이월) 연간 잔여: 64.5 x 12 = 774만 원 과세표준: 774만 원 → 세율 6% 종합소득세: 약 46만 원 지방소득세: 약 5만 원 ───────────────────────── ★ 연간 총 세금: 약 51만 원 ★ (비용처리 안 하면? 2,640만 원 전액 과세 → 세금 약 270만 원) ★ 절세 효과: 연 약 219만 원 ★

역할별 돈의 흐름

역할받는 돈 (월)내는 돈 (월)연간 효과
딸관리수수료 17.5만 + 잔여 64.5만강사비, 재료비 등 집행소득 774만 → 세금 약 51만
아버지임대료 50만 + 원임대료 20만관리수수료 17.5만수수료가 필요경비 공제 → 절세
회원—회비 22만변동 없음
교회공간 사용월세 28만변동 없음 (증빙 주체만 변경)
