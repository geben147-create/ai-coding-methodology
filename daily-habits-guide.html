1. 역할별 해야 할 일 총정리

딸 (87년생 / 실질 운영자) — 가장 할 일이 많음

주기할 일구체적 방법
매일영수증 수집단체 관련 지출 시 반드시 카드 결제 또는 현금영수증 (단체 고유번호 입력)
매일지출 메모핸드폰 메모앱이나 엑셀에 "날짜 / 금액 / 용도 / 증빙유형" 기록
매일관리 업무 일지건물 관련 업무(전화, 방문, 수리 등) 발생 시 일지 한 줄 기록
매주영수증 정리종이 영수증 사진 촬영 후 월별 폴더에 보관, 엑셀에 입력
매월 5일회비 입금 확인단체 통장 접속 → 회원별 입금 확인 → 회비대장 체크
매월 말월간 정산수입/지출 엑셀 마감, 잔액 확인, 영수증 누락 체크
매월 10일원천세 납부강사비 지급 시 3.3% 원천징수 → 홈택스에서 신고·납부
매월 말건물 관리 보고아버지에게 월세 수금 현황, 시설 점검 결과, 지출 내역 보고
분기회비 사용 내역 공개회원들에게 3개월 수입/지출 요약 공유 (카톡 또는 모임)
1월연간 결산전년도 수입/지출 총정리 → 결산보고서 작성
5월종합소득세 신고홈택스에서 단체 수익사업 소득 신고 (또는 세무사 위임)

아버지 (건물 소유자) — 할 일 적음

주기할 일구체적 방법
1회전대 동의서 서명교회 전대차에 대한 서면 동의서 작성 (1번만)
1회관리위탁 계약서 서명딸과 건물 관리 위탁 계약 체결 (1번만)
매월관리 수수료 이체매월 말 딸(단체) 계좌로 17.5만 원 이체
수시대규모 수리 승인50만 원 초과 수리 시 딸이 문자/카톡으로 승인 요청 → "OK" 회신
매월영수증 전달건물 관련 지출(수리비, 관리비 등) 영수증을 딸에게 전달
5월종합소득세 신고본인 임대소득 신고 (기존과 동일, 관리 수수료는 경비 처리)

동호회 회원 — 할 일 거의 없음

주기할 일구체적 방법
매월 5일회비 납부22만 원을 단체 전용 통장으로 이체 (반드시 본인 이름으로)
수시특별활동비 납부행사/대회 참가 시 추가 비용 단체 통장으로 이체
연 1회정기총회 참석1월 정기총회 참석, 회비 결정 투표

회장 (85년생 언니) — 할 일 거의 없음

주기할 일구체적 방법
연 1회정기총회 참석총회에서 결산 승인, 사업계획 승인
수시주요 의사결정 참여대규모 지출, 행사 결정 시 딸과 협의
비고회장이 대표가 아닌 경우 실질적 업무 없음. 대표(87년생)가 모든 실무 수행.

2. 매일 습관 — 생활 속 비용처리 루틴

비용처리의 핵심은 "증빙을 남기는 습관"입니다. 아래를 매일 반복하세요.

매일 루틴 3줄 요약:
1. 단체 관련 지출은 무조건 카드로 결제 (현금 시 현금영수증 필수)
2. 결제 즉시 핸드폰 메모에 "날짜/금액/용도" 한 줄 기록
3. 건물 관련 업무 발생 시 업무 일지 한 줄 기록

영수증 수집 — 이렇게 하세요

[카드 결제 시] (추천 - 가장 편함) 단체 업무용 체크카드 1장을 지정 → 모든 단체 관련 지출은 이 카드로만 결제 → 월말에 카드사 홈페이지에서 내역 다운로드 → 자동으로 증빙 완료! [현금 결제 시] (가급적 피하세요) → 결제 시 "현금영수증 해주세요" + 단체 고유번호 입력 → 또는 핸드폰 번호로 현금영수증 발급 → 종이 영수증은 사진 찍어 보관 (3년 이상) [온라인 구매 시] → 단체 이름으로 세금계산서 요청 → 또는 현금영수증 자동 발행 확인 → 이메일로 받은 영수증 "단체 증빙" 폴더에 보관

3. 매주 습관 — 주간 정리 (일요일 저녁 30분)

[주간 체크리스트] 매주 일요일 저녁 □ 이번 주 영수증 모았는가? → 종이 영수증 사진 촬영 → "2026-04" 폴더에 저장 → 카드 내역 확인 (빠진 거 없는지) □ 엑셀 지출 기록 업데이트했는가? → 이번 주 메모한 내용을 엑셀에 정리 입력 → 카테고리(교재비/임차료/강사비 등) 정확히 분류 □ 관리 업무 일지 빠진 날 없는가? → 건물 관련 업무 있었으면 기록 → 없었으면 "특이사항 없음"이라도 한 줄 □ 다음 주 예정된 지출 확인 → 강사비 지급일, 임차료 납부일 등 체크 소요 시간: 약 20~30분

월간 스케줄

매월 말관리 보고딸아버지에게 월세 수금·시설·지출 보고 (카톡 OK)

월말 정산 체크리스트
