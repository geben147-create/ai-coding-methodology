3. 두 방법론 비교: GSD+speckit vs kit-templates

항목🔴 GSD + speckit🟡 kit-templates
워크플로우 엔진/gsd:* 명령어없음 (Claude에게 직접)
계획 파일.planning/ 자동 생성없음
명세서specs/001-xxx/specs/_template/feature.md
AI 지시CLAUDE.mdCLAUDE.md + AGENTS.md + 00-METHODOLOGY.md
학습 기록LessonsLearned.mdLEARN.md + DECISIONS.md
복잡도높음 (phase/plan)낮음 (파일만)
적합대형 (5+ 페이즈)소형~중형
브랜치speckit/001-xxx자유
통합 결론
Mode A = kit만  |  Mode B = Spec Kit + kit  |  Mode C = Spec Kit + BMAD + kit
Mode A ⊂ Mode B ⊂ Mode C — 상위가 하위를 완전히 포함
