1차 감사 프롬프트 — 보고만, 수정 금지
먼저 이걸 돌려서 현황 파악. 절대 수정하면 안 됨.
너는 Captain 세션이다. 작업명: 소스 가비지/중복 파일 정리 감사 절대 금지: - 바로 삭제 금지 - 바로 rename 금지 - git add . 금지 - commit 금지 - push 금지 - public/trusta 삭제 금지 - src/components/dashboard-v2 삭제 금지 - lex-preview, mockups-preview 삭제 금지 - migration 파일 건드리기 금지 먼저 확인만 해: 1. git status -sb 2. git status --short 3. find 또는 Get-ChildItem으로 루트의 이상 파일 확인 4. specs/014, 015, 016, 017 폴더 구성 비교 5. rg "/trusta|public/trusta|dashboard-v2|lex-preview|mockups-preview" 6. rg "fetch_results|discovery_results|_design_bundle|\.planning/debug" 7. git ls-files로 이미 Git에 추적 중인 파일인지 확인 8. 삭제/보관/rename/.gitignore 후보를 표로 분류 출력: - 바로 삭제 가능 - .gitignore 추가 권장 - archive로 이동 권장 - 커밋해야 할 문서 - 절대 삭제 금지 - 실제 삭제 명령어 초안 - 삭제 후 검증 명령어 보고만 하고 수정하지 마.

2차 정리 프롬프트 — 감사 결과 확인 후 실행
1차 보고 받고 본인이 판단한 다음에 이걸 실행. commit/push는 절대 포함 안 됨.
좋아. 아래 항목만 정리해. 삭제: - = - .planning/debug/ - fetch_results.py - fetch_results2.py - discovery_results.txt .gitignore 추가: - .planning/debug/ - _design_bundle/ - fetch_results*.py - discovery_results.txt specs 정리: - specs/014-sidebar-ia-reorder/ - specs/015-sidebar-ia-reorder/ - specs/016-sidebar-menu-reorder/ 단, 삭제 전 specs/017-sidebar-ia-cleanup/에 내용이 흡수됐는지 다시 확인해. 절대 건드리지 말 것: - public/trusta/ - docs/PRD-ALL.md - docs/design-handoff/ - src/components/dashboard-v2/ - src/app/lex-preview/ - src/app/mockups-preview/ - supabase/migrations/ 실행 후: 1. git status --short 2. git diff --name-status 3. pnpm build 4. 삭제/수정된 파일 목록 5. 커밋 메시지 제안 git add, commit, push는 하지 마.

확인 후 삭제

빌드 검증 + 커밋 준비
정리 완료 후 커밋 전 마지막 단계
빌드 + 상태 확인
pnpm build 빌드 결과 에러 없으면 git status --short 보여줘. 삭제된 파일 목록이랑 .gitignore 변경 내역 정리해줘.
커밋 메시지 제안 요청
삭제/정리된 파일 목록 기준으로 conventional commit 형식 커밋 메시지 제안해줘. git add ., commit, push는 하지 마.
.gitignore 업데이트
임시 파일이 계속 생기는 경우
추가 요청
.gitignore에 아래 패턴 추가해줘: - .planning/debug/ - _design_bundle/ - fetch_results*.py - discovery_results.txt 추가 후 파일 내용 확인해줘.
이미 추적 중인 파일 제거
git ls-files --cached [파일명] 캐시에 있으면 git rm --cached [파일명] .gitignore에도 추가해줘.
