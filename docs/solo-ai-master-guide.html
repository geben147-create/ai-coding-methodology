Module B: 명세 + 설계 + AI 교차검증

방1 Beck 60% 방3 자막 70%

6 Phase 워크플로우

1
INTENT - 명세 작성
/speckit.constitution + /speckit.specify + /speckit.clarify
▼
2
DESIGN - 설계 + 교차검증
/speckit.plan + pal:consensus (gpt-5.2-pro FOR + gemini AGAINST)
▼
3
DECOMPOSE - 작업 분해
/speckit.tasks + /speckit.analyze
▼
4
BUILD - TDD 구현 (Beck 루프)
ai-start + go → RED → GREEN → REFACTOR → atomic commit
▼
5
VERIFY - 검증
pal:secaudit + pal:codereview + pal:challenge
▼
6
SHIP - 배포
ai-done "feat: ..." -Merge
18분 자막 핵심: 6명 만장일치는 연극. 1 for + 1 against 1라운드면 충분. 교차검증은 중요 설계 결정 시만 실행.

  models=[

Module C: 구현 + 검증 + 배포

방1 TDD 60% 방4 CLI 50%

Phase 4 - BUILD (TDD 루프)

# 브랜치 생성
ai-start login    # → feat/login-20260412

# Claude Code
claude

# TDD 루프 시작
go
# 1. RED   → 실패 테스트 작성
# 2. GREEN → 최소 코드로 통과
# 3. REFACTOR → 리팩토링
# 4. COMMIT → 100줄 이하 atomic
# 5. CHECK → plan.md [x] 체크

Phase 5 - VERIFY

pal:secaudit      # 보안 검증
pal:codereview    # 코드 리뷰
pal:challenge "보안 안전 주장 비판"   # 선택
pal:precommit     # 커밋 전 게이트

Phase 6 - SHIP

# 커밋 + 푸시
ai-done "feat(auth): JWT login"

# 커밋 + 푸시 + main 병합
ai-done "feat(auth): JWT login" -Merge

Anti-Patterns + 실패 모드

절대 하지 마라

6명 AI 만장일치가짜 동의 (연극)
spec 없이 코딩"무엇을" 모르고 시작
테스트 나중에나중 = 안 함
100줄 초과 커밋리뷰 불가능
CLAUDE.md 200줄+AI가 무시

알려진 실패 모드

얕은 테스트→ contract test 강제
Integration 회귀→ staging 검증
Security-by-doc→ CI 게이트 필수
Drift silent fail→ "BLOCKED" 강제

빠른 시작 체크리스트

1. PowerShell 프로필에 함수 붙여넣기 (최초 1회)

4. claude 실행
5. /speckit.constitution (헌법)
6. /speckit.specify "기능"
7. /speckit.plan (설계)

9. go (TDD 루프)
10. ai-done "feat: 완료" -Merge

Drift Control (CLAUDE.md 필수 추가)

# DRIFT CONTROL
If implementation diverges from spec.md:
  a) Update spec.md AND DECISIONS.md in SAME commit, OR
  b) STOP and ask human. NEVER silently drift.

# UNCERTAINTY
If ambiguous, output "BLOCKED: <질문>" - NEVER guess.
