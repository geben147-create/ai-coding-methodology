❓ 자주 묻는 질문
Q. AI가 법적 책임도 보장해주나요? ▾
아니요. TRUSTA는 위험 가능성을 사전에 발견하는 보조 도구입니다. 법적 최종 판단은 전문가와 함께해야 합니다. 다만 위험 문구를 사전에 걸러냄으로써 분쟁 가능성을 현저히 낮출 수 있습니다.
Q. 어떤 언어와 국가를 지원하나요? ▾
현재 한국어와 영어를 지원하며, 한국(식약처·공정위), 미국(FTC), EU(EASA), 일본(소비자청) 기준을 탑재하고 있습니다. 향후 중국어·일본어와 추가 국가 기준을 지속 업데이트합니다.
Q. API 연동은 어떻게 하나요? ▾
REST API 형태로 제공됩니다. Make(Integromat), Zapier, n8n 등 자동화 도구와 손쉽게 연동되며, 직접 코드로 연동하는 경우 상세 문서를 제공해드립니다. 엔터프라이즈 파운더 리워드의 경우 온보딩 세션을 통해 직접 설정을 도와드립니다.
Q. Threads 자동화 연동은 언제부터 되나요? ▾
정식 출시(2024 Q3)와 함께 Threads API 연동을 지원할 예정입니다. 현재 베타 테스터를 모집 중이며, 얼리버드 참여자에게 우선 베타 접근 권한을 드립니다.
