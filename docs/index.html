3. 저가매매 세금 시뮬레이션

저가매매 증여세 계산 공식

1단계: 차액 = 시가 - 매수가
2단계: 기준금액 = MIN(시가 x 30%, 3억원)
3단계: 과세여부 판단 = 차액 > 기준금액?

5단계: 증여세 = (증여재산가액 - 직계존비속 공제 5,000만) x 세율

5. 자금 흐름 분석 프레임워크

부녀간 복잡한 자금 흐름(증여/대여/투자/생활비 혼재)을 정리하기 위한 분석 구조입니다.

5-1. 자금 흐름 분류 기준

구분세무 처리입증 방법위험도
증여 (아버지→딸)10년 5천만 공제, 초과분 증여세계좌이체 내역중
대여 (아버지→딸)적정이자(4.6%) 미수취시 증여 의제차용증, 상환내역고

대여 (딸→아버지)이자소득 or 무이자 시 문제없음차용증, 계좌내역저
투자금 (공동)원금+수익 분배 기준 증여 판단투자계약서, 거래내역고
생활비/부양사회통념상 비과세사용 용도 증빙저

5-2. 딸→아버지 자금 이전 (상계 가능 금액 산정)

예시 1: 계좌 기반 상계 처리

딸이 2020~2025년간 아버지에게 총 8,000만원을 이체한 기록이 있고, 아버지가 딸에게 3,000만원을 이체한 기록이 있는 경우:

순이전액(딸→아버지) = 8,000만 - 3,000만 = 5,000만원
→ 이를 아버지의 채무로 인정받으면, 매매대금 중 5,000만원을 상계 처리 가능
→ 나머지 1억원만 실제 지급하면 됨 (1.5억 - 5,000만 상계)
주의: 상계 처리를 위해서는 차용증 또는 채무확인서가 필요하며, 계좌이체 내역이 증빙이 됩니다.

예시 2: 비트코인/바이낸스 공동 운용 정리

딸이 아버지에게 투자 목적으로 2,000만원을 전달하고, 바이낸스에서 공동 운용 후 현재 가치가 1,200만원인 경우:

투자원금: 2,000만원 (딸 출자)
현재 가치: 1,200만원
손실: 800만원 (40% 손실)
→ 투자 손실분 800만원은 아버지의 관리 책임 주장 가능
→ 또는 원금 2,000만원을 채권으로 인정받아 매매대금 상계에 활용
암호화폐 거래는 계약서, 거래소 입출금 내역, 지갑 주소 이력으로 증빙합니다.

5-3. 최소/최대 시나리오

최소 시나리오 (딸→아버지 순이전 최소)

아버지→딸 자금을 투자 원금/생활비로 인정, 딸→아버지 자금 중 투자금 환수분 제외

순이전액: ~2,000만원

최대 시나리오 (딸→아버지 순이전 최대)

딸→아버지 모든 이체를 대여금으로, 아버지→딸 자금은 투자수익 환원으로 처리

순이전액: ~8,000만원+

7. 시각화 예시

예시 1: 연도별 매매 vs 전세 가격 비교

이 차트에서 알 수 있는 것

  • 2020년 이후 매매가 급등 (1.5억대 → 2.3억대)
  • 전세가는 상대적으로 안정 (1.0억~1.7억대)
  • 전세가율: 약 65~74% (매매 대비 전세 비율)
  • 2024~2026년 매매가 안정화 추세 (2.2~2.5억 박스권)

예시 2: 매수가별 세금 부담 비교

이 차트에서 알 수 있는 것

  • 1억 6,100만원이 증여세 없는 안전 최저가 (시가의 70%)
  • 1억 5,000만원 매수 시 증여세 자체는 0원(공제 내)이지만, 과세 "대상"이 됨 → 세무 리스크
  • 취득세는 매수가에 비례하므로, 낮은 가격 = 낮은 취득세
  • 최적 매수가: 1억 6,100만~1억 7,000만원 (증여세 없음 + 취득세 최소)

8. 최종 권고안

추천 A: 안전한 최저가 매수

매수가: 1억 6,100만원

  • 시가(2.3억)의 정확히 70%
  • 증여세: 0원 (과세 대상 아님)
  • 취득세: ~177만원
  • 세무 리스크: 매우 낮음
가장 안전하면서 최대한 절세

추천 B: 과거 자금 상계 활용

매수가: 1억 5,000만원 + 상계 처리

  • 계약서상 매수가: 1.5억
  • 증여재산가액: 1,100만 (공제 내)
  • 과거 딸→아버지 자금을 상계로 활용
  • 세무 리스크: 중간 (증빙 필요)
계좌 내역 + 채무확인서 필수

비추천: 무증빙 저가 매수

매수가: 1억 5,000만원 (증빙 없이)

  • 국세청 소명 요청 시 대응 어려움
  • 과거 증여 미신고분 소급 과세 가능
  • 가산세(20~40%) 추가 위험
  • 세무 리스크: 높음
