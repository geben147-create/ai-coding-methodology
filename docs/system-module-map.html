INFRA 3 + CAT 14 = 17 Units
의존성 흐름도
CAT-3 상태 머신
COLLECTED→ SCORED→ SELECTED→ OUTLINED→ SCRIPTED→ STYLED→ PROMPTED→ GENERATED→ ASSEMBLED→ RENDERED→ DISTRIBUTED
INFRA: 인프라 레이어 (모듈 아님 — 횡단 서비스)
INFRA-A Google Sheets 제어 계층
설정 저장소 + 수동 제어판. 읽기는 모든 CAT 허용, 쓰기는 CAT-3만.
  • 스코어링 가중치/필터 (CAT-2)
  • 채널별 스타일 프롬프트 (CAT-7)
  • 외부 이미지 매핑 (CAT-9)
  • 캐릭터 slot map (CAT-6)
  • 라우팅 규칙 (동적 브랜칭 없음)
INFRA-B 외부 API 레지스트리
모든 외부 API 호출의 단일 진입점. 직접 호출 금지.
  • YouTube V3 / Sheets / Drive API
  • NotebookLM / Gemini / Perplexity
  • Z-Image / VibeVoice / Index TTS
  • OpenAI (대체용) / GenSpark
  • Rate limit + Retry + Fallback 내장
INFRA-C FFmpeg 런타임
미디어 처리 공유 엔진. 버전/설치 단일 관리.
  • Scene detect + Keyframe (CAT-4)
  • 슬라이드쇼 → 영상 변환 (CAT-11)
  • 클립 병합 / 자막 / BGM (CAT-11)
CAT 0~13: 모듈 상세
CAT-0 CHANNEL ROUTER
최상위 분기. channel_id → 불변 config 객체 주입. 채널 간 데이터 격리.
  • character_set_id → CAT-6
  • style_prompt_id → CAT-7
  • scoring_weights → CAT-2
  • category_rules → CAT-2
  • distribution_target → CAT-12
CAT-1 MULTI-SOURCE INPUT
원시 데이터 수집 + 정규화. 반드시 CAT-3 경유 출력.
  • 1-A. YouTube V3 수집기 (~50개, 자막, 23카테고리)
  • 1-B. URL / PDF / 텍스트 입력
  • 1-C. Instagram 크롤러 placeholder
  • 1-D. Research API 보강 (NLM/Gemini/Perplexity)
  • 1-E. Source Merger + Normalizer
CAT-2 SCORING ENGINE
YouTube V3 전용. 21개 로직 + 가중치 결합 → Top-N 선정.
  • 2-A. 21개 로직 (z-VPH, Red Ocean 등, ~80% 작동)
  • 2-B. 스코어 결합기 (가중치/정렬/필터)
  • 2-C. Top-N 선택기 → CAT-3 상태 업데이트
  • 2-D. 제어 옵션 패널 (Sheets, 수동 편집)
CAT-3 LIBRARY_RESULT (SSOT)
단일 정본. 모든 파이프라인의 System of Record.
  • content_id / library_id / channel_id / character_id
  • 상태 머신: 11단계 순방향 전이만 가능
  • read(id, fields) / write(id, field, val)
  • lock_field(id, field) / transition(id, status)
  • 외부 URL 재조회 금지 / 직접 수정 금지
CAT-4 STRUCTURE & VISION LOCK #1 PARALLEL
아웃라인 뼈대 + 소스 영상 키프레임 추출. 4-AB/4-CD 병렬.
  • 4-A. n_steps 결정기
  • 4-B. 스토리 뼈대 → outline_structure LOCK
  • 4-C. FFmpeg Scene Detect (INFRA-C)
  • 4-D. Keyframe Extraction → vision_prompt_raw (READ-ONLY)
CAT-5 WRITING CORE LOCK #2
N-Step 스크립트 생성. Step별 개별 프롬프트 입력.
  • 5-A. Outline → 실제 글 Outline
  • 5-B. Hook Draft
  • 5-C. Final Hook / Title 확정
  • 5-D. Step-by-Step 스크립트
  • 5-E. Final Merge → final_merged_text LOCK
  • 5-F. Translation Side-Car 선택
  • 5-G. Variant Row Generator 선택
CAT-6 CHARACTER RESOLVER
장면별 캐릭터/음성 고정. AI 자동 추론 금지 — slot map만.
  • 6-A. Slot Map (금융→곰, 건강→토끼 등)
  • 6-B. Scene별 character_id 할당
  • 6-C. Scene별 voice_id 할당
  • 출력: {scene_id → (character_id, voice_id)}
CAT-7 STYLE DIRECTOR
시각 일관성. 스타일 "생성" 아님 — "규칙 주입"만.
  • 7-A. Style Profile (mood/camera/lighting/B-roll/색감)
  • 7-B. 채널별 고정 프롬프트 (Sheets, 자동삽입)
  • 7-C. Reference Image 시스템 선택
CAT-8 PROMPT ASSEMBLY LOCK #3
TEXT/IMAGE/VIDEO 최종 프롬프트 조립 + hashId 무결성.
  • 8-A. 프롬프트 템플릿 엔진 (스타일+장면+캐릭터)
  • 8-B. Hash 생성기 (SHA256 → hashId)
  • 8-C. Hash 검증 게이트키퍼 FAIL=중단
  • 동적 브랜칭 없음 — 시트 제어 라우팅
CAT-9 MEDIA GENERATION 9A∥9B∥9C
이미지 + 음성 + 썸네일. 3개 하위 모듈 내부 병렬.
  • 9-A. Image (Z-Image + 외부 벌크 업로드 + 범위 교체)
  • 9-B. Audio (VibeVoice=감정 / IndexTTS=내레이션)
  • 9-C. Thumbnail (후순위) 후순위
CAT-10 SCENE ORCHESTRATOR
장면별 시각 소스 라우팅 + 클립 준비. R47/R40/R48 불변.
  • 10-A. Scene Mode (AI / SLIDE / MIXED)
  • 10-B. Scene Duration (N초)
  • 10-C. 외부 이미지 → Scene 매핑
  • 10-D. 부분 장면 재생성
CAT-11 VIDEO ASSEMBLY
최종 영상 합성. scene_id가 마스터 단위.
  • 11-A. 슬라이드쇼 → 영상 클립 (INFRA-C)
  • 11-B. 클립 병합
  • 11-C. 자막 삽입
  • 11-D. 배경 음악 삽입
  • 11-E. 최종 렌더링 → final_video_url
CAT-12 SCHEDULING & DISTRIBUTION
채널별 독립 배포. 재시도 로직 포함.
  • 12-A. 스케줄러 (예약 게시 큐)
  • 12-B. 채널별 배포 라우팅 + 메타데이터/썸네일
CAT-13 VERIFICATION & QUALITY GATE
전 구간 검증. 수정 권한 없음, FAIL 시 해당 CAT 재처리.
  • 13-A. hashId 무결성 검증
  • 13-B. GenSpark 100회 배치 테스트
  • 13-C. Contract Test (모듈간 스키마)
  • 13-D. Staging 검증 (재생 + 동기화)

충돌 방지 핵심 규칙
scene_id = 마스터 키
모든 자산(스크립트, 오디오, 이미지, 자막)은 scene_id로만 연결
channel_id = 분기 키
채널 간 데이터/설정 절대 공유 안 함
LIBRARY_RESULT = SSOT
모든 읽기/쓰기의 단일 진입점
LOCK 3개
outline_structure, final_merged_text, hashId — LOCK 이후 수정 불가
기존 워크플로 불변
R47, R40, R48 수정 금지 — 새 레이어만 추가
명시적 할당만
캐릭터/이미지 매핑에 AI 자동 추론 금지
인프라 ≠ 모듈
Sheets, API, FFmpeg는 횡단 인프라 레이어
단방향 의존
CAT-N → CAT-(N+k)만 소비. 역방향 금지 (CAT-3 예외)
