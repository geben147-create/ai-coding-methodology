2. 모드별 프로젝트 시작 (따라하기)

Mode A — 소형 (스크립트, 도구, 실험)

ai-new my-tool                    # 1분 세팅, 7개 파일 복사
cd-repo my-tool
# AGENTS.md 열어서 기술스택 채우기
ai-start feature-name             # 브랜치 생성
claude                            # Claude Code 시작
# → "AGENTS.md 읽고, OOO 기능 만들어줘"
ai-done "feat: xxx" -Merge        # 커밋+병합

복사 파일: AGENTS.md, CLAUDE.md, LEARN.md, scratchpad.md, ARCHITECTURE.md, DECISIONS.md, README.md

Mode B — 중대형 (기능 5+, 상용)

ai-new my-saas -Mode B            # Spec Kit + 템플릿
cd-repo my-saas
claude

Claude Code 안에서 (최초 1회):

/speckit.constitution
  → 기술 스택: Next.js 15 + FastAPI + PostgreSQL
  → 보안: OWASP Top 10
  → 테스트: TDD, 커버리지 80%+

기능마다 반복:

/speckit.specify "사용자 로그인 (이메일+JWT)"
/speckit.clarify      ← 모호함 제거
/speckit.plan         ← 아키텍처 계획
/speckit.tasks        ← DAG 작업 분해
/speckit.analyze      ← 헌법 위반 체크
/speckit.implement    ← 코드 작성

Mode C — 대형 (6개월+, 엔터프라이즈)

ai-new huge-app -Mode C           # Spec Kit + BMAD + 풀셋

/speckit.constitution             # NFR 정의

5. 대형 프로젝트 5단계 파이프라인

18분 자막 핵심: BMAD spec + Beck TDD execution + CONTROL-MAP compliance

Phase 1 — SPEC (~3hr) ├─ BMAD brainstorming (1hr) → user flow 발굴 ├─ Claude Code → spec.md (Goals / Non-goals / Acceptance Criteria) ├─ PAL consensus (gpt-5.2-pro for + against, 1 round) ├─ CONTROL-MAP.md v0 작성 └─ 사용자 최종 승인 Phase 2 — PLAN (~1hr) ├─ spec → plan.md 분해 (각 task 2~5분) ├─ 각 task에 DoD (test / lint / checkbox / commit) └─ 사용자 검토 Phase 3 — BUILD (세션 루프) ├─ "go" → CLAUDE.md 룰 자동 ├─ RED → GREEN → REFACTOR ├─ atomic commit (structural OR behavioral) ├─ plan.md [x] + 메모 └─ Drift → spec 업데이트 or STOP Phase 4 — VERIFY ├─ Tests + lint + secret scan ├─ PAL codereview (auth/data/security 변경 시) ├─ CONTROL-MAP evidence 검증 └─ 머지 Phase 5 — EVOLVE ├─ 5분 회고 ├─ DECISIONS.md 업데이트 └─ CONTROL-MAP drift 점검
