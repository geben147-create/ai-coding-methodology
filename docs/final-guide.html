모듈 C: 일일 개발 루프 매일

방법론 1(TDD) 60% + 방법론 4(CLI) 50%

C-1. 작업 시작

claude                       # Claude Code 시작

C-2. TDD 실행 루프 (방법론 1: 60%)

Claude Code 안에서 "go" 한 마디: 1. plan.md에서 첫 미완료 task 찾기 2. 실패하는 테스트 작성 (RED) 3. 테스트 실행 → 실패 확인 4. 최소 코드 작성 (GREEN) 5. 테스트 실행 → 통과 확인 6. 리팩토링 7. plan.md [x] 체크 + 인수인계 메모 8. STOP
Kent Beck 규칙내용
RED-GREEN실패 테스트 먼저 → 최소 코드로 통과
100줄 제한커밋당 변경 100줄 이하
Tidy First구조 변경과 동작 변경은 별도 커밋
Drift Controlspec에서 벗어나면 즉시 STOP

C-3. 마감 (방법론 4: 50%)

# 커밋 + 푸시 (브랜치 유지)
ai-done "feat(auth): add email login with JWT"

# 커밋 + 푸시 + main 병합 (완료)
ai-done "feat(auth): add email login with JWT" -Merge

# WIP 저장 (미완료)
ai-done "wip: login halfway done"
