📝 예시 1: 10년 보유 수익률 계산

상황: 2015년 1.5억에 매수 → 2026년 현재 시가 2.3억

수익률 = (현재시가 - 매수가) / 매수가 × 100
= (23,000 - 15,000) / 15,000 × 100
= 53.3% (10년간)
연평균 수익률 ≈ 4.4%/년

🔍 같은 기간 전국 아파트 평균 상승률 약 40~60%와 비슷한 수준이며, 2022년 고점(3억) 대비로는 현재 조정된 상태입니다.

📝 예시 2: 전세가율로 본 투자 수익

상황: 매수가 1.5억, 전세 놓은 가격 1.3억 (2016년 평균 전세가)

실투자금 = 매수가 - 전세보증금 = 15,000 - 13,000 = 2,000만원
현재 시가 = 23,000만원
전세금 반환 후 순자산 = 23,000 - 13,000 = 10,000만원 (1억원)
투자금 2천만원 → 순자산 1억원 = 수익률 400%

🔍 갭투자(전세 레버리지) 기준으로 보면 실투자금 대비 매우 높은 수익률입니다. 단, 이 구조는 저가매매 시 전세 보증금 처리가 핵심 이슈가 됩니다.

2. 저가매매 기준 및 안전 가격대 설정

📌 법적 근거: 상속세 및 증여세법 제35조(저가양수에 따른 이익의 증여)
판단 기준: 시가 대비 30% 초과 차이 또는 3억원 초과 차이 → 증여세 과세
시가 정의: 감정평가액 또는 유사 매매사례가액 (공시지가가 아닌 실거래가 기준)

📝 예시 1: 안전한 저가매매 (통과)

상황: 시가 2억3천 기준, 매매가 1억7천으로 계약

시가와의 차이 = 23,000 - 17,000 = 6,000만원
시가의 30% = 23,000 × 0.3 = 6,900만원
차이(6,000) < 30%기준(6,900) ✅ → 증여세 비과세
차이(6,000) < 3억원 ✅ → 안전

✅ 1억7천만원 매매는 시가 2억3천 대비 26% 할인으로, 30% 이내이므로 증여세 과세 대상이 아닙니다.

📝 예시 2: 위험한 저가매매 (과세)

상황: 시가 2억5천 기준, 매매가 1억5천으로 계약

시가와의 차이 = 25,000 - 15,000 = 10,000만원 (1억원)
시가의 30% = 25,000 × 0.3 = 7,500만원
차이(10,000) > 30%기준(7,500) ❌ → 증여세 과세!

증여 간주액 = 차이 - 시가의 30% = 10,000 - 7,500 = 2,500만원
(단, 증여재산공제 5,000만원 적용 시 → 증여세 0원 가능)

⚠️ 30%를 초과하더라도 직계존비속 증여재산공제(10년간 5천만원)가 남아있으면 실제 세금은 0원일 수 있습니다. 다만, 과거 증여 이력이 있으면 공제가 줄어듭니다.

🔵 시나리오 A: 딸→아버지 순이전 최대화 (상계 유리)

딸이 아버지에게 보낸 금액이 최대한 많다고 볼 때

구분항목금액(예시)
딸→아버지투자금 송금+5,000만원
딸→아버지생활비 지원+2,000만원
딸→아버지암호화폐 투자금+3,000만원
아버지→딸용돈/생활비-1,000만원
아버지→딸투자수익 반환-500만원
딸→아버지 순이전 최대치+8,500만원

→ 이 금액을 아버지의 채무로 인정받을 수 있으면, 매매대금에서 상계 처리 가능

🔴 시나리오 B: 아버지→딸 순이전 최대화 (증여 리스크)

아버지가 딸에게 보낸 금액이 최대한 많다고 볼 때

구분항목금액(예시)
아버지→딸창업자금 지원+5,000만원
아버지→딸생활비/결혼자금+3,000만원
아버지→딸투자금 반환+2,000만원
딸→아버지투자금 송금-3,000만원
딸→아버지생활비-500만원
아버지→딸 순이전 최대치+6,500만원

→ 이 금액이 증여로 간주되면, 10년간 5천만원 공제 후 나머지에 증여세 부과 가능

📝 예시 1: 상계 처리가 유리한 경우

상황: 계좌 분석 결과 딸→아버지 순이전 8,500만원 확인

매매대금: 17,000만원
상계 처리: -8,500만원 (과거 채무)
실제 지급액: 17,000 - 8,500 = 8,500만원

→ 딸이 즉시 지급할 금액이 8,500만원으로 줄어듦
→ 나머지 8,500만원은 과거 아버지의 채무를 갚는 것으로 처리

✅ 계좌 이체 내역이 명확하면, 채무확인서 + 상계합의서로 세무 리스크 최소화 가능

📝 예시 2: 분할 상환 구조가 유리한 경우

상황: 딸이 즉시 지급 가능한 금액이 2~3천만원뿐인 경우

매매대금: 17,000만원
즉시 지급: 2,500만원
상계 처리: 6,000만원 (입증 가능한 부분만)
잔금(분할상환): 17,000 - 2,500 - 6,000 = 8,500만원

분할 상환 조건: 월 70만원 × 12개월 = 840만원/년
이자율: 연 4.6% (세법상 적정이자율) → 연 이자 약 39만원
총 상환기간: 약 10년

⚠️ 분할상환 시 차용증을 반드시 작성하고, 실제로 매월 이체 기록을 남겨야 합니다. 이자를 지급하지 않으면 이자 상당액이 증여로 간주될 수 있습니다.
