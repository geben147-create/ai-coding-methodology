6-2. 전세가와 매매 전략의 관계

전세가-매매 전략 핵심:
• 전세 낮게(1.6억) → 갭 커짐 → 갭투자자 유입 어려움 → BUT 임대 수익 안정, 보증금 반환 부담 적음
• 전세 높게(1.7억) → 갭 작아짐 → 갭투자 매력 상승 → BUT 공실 리스크, 보증금 반환 부담 큼
• 향후 매도 계획이 있다면: 전세를 낮게 설정하여 안정적 임대 운영 후 매도가 유리
