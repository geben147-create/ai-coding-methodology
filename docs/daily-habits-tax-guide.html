2. 인물별 역할 분배

딸 딸이 해야 할 것 (핵심 실무자)

  • 매일 영수증 수집 + 뒷면 메모 (용도/참석자)
  • 매일 카드 결제 문자 → 즉시 메모앱에 기록
  • 매일 현금 지출 시 반드시 간이영수증 요청
  • 매주 엑셀 입력 (영수증 → 스프레드시트)
  • 매주 영수증 사진 촬영 → 클라우드 폴더 저장
  • 매월 월간 카테고리별 집계표 작성
  • 매월 통장 내역서 PDF 다운로드
  • 매월 아버지에게 자금 이체 시 반드시 "용도" 기재
  • 분기 분기 결산 보고서 작성
  • 연간 연간 결산서 + 세무 신고 준비
  • 수시 부동산 매매 관련 서류 준비 (계좌 내역 정리)
  • 수시 과거 자금이체 내역 역추적 및 분류
💡 딸의 핵심: "증빙의 여왕"이 되어야 합니다. 모든 돈의 흐름에 종이(영수증/계약서/이체확인서)를 붙이세요.

아버지 아버지가 해야 할 것

  • 매일 동호회 관련 지출 시 카드 결제 + 영수증
  • 매일 현금 거래 시 반드시 영수증 수령 → 딸에게 전달
  • 매주 한 주간 영수증 모아서 딸에게 전달
  • 매월 통장 정리 (본인 명의 계좌)
  • 매월 딸에게 돈 보낼 때 이체 메모에 "목적" 기재
  • 분기 딸이 만든 결산 보고 확인 서명
  • 수시 부동산 관련 서류 (등기부, 계약서) 보관
  • 수시 과거 자금 이체 내역 확인 협조
💡 아버지의 핵심: "영수증만 잘 모아서 딸에게 전달"하면 됩니다. 기록은 딸이 합니다.

회장님 회장님이 해야 할 것 (최소한)

  • 분기 결산 보고서 확인 + 서명/날인
  • 연간 연간 총회에서 결산 승인
  • 수시 대외 공문/계약서 대표 서명 (필요 시)
  • 수시 법인 통장 인감/공인인증서 관리
💡 회장님은 거의 할 게 없습니다. 집을 파는 게 아니니까. 분기에 한 번 서류 확인 + 서명이 전부입니다.

동호회원 동호회원이 해야 할 것

  • 매월 회비를 반드시 계좌이체로 납부 (현금 금지)
  • 수시 행사 참가비도 계좌이체로
  • 수시 동호회 명의로 구매한 물품 영수증 → 딸에게 전달
  • 수시 차량 지원 시 주유 영수증 제출
💡 동호회원의 핵심: "회비는 현금 NO, 계좌이체 YES" 이것만 지키면 됩니다.
