# Korean Ranking Highlight Editor

## 사용 시점

- 랭킹 쇼츠의 컷 길이와 순위 전환을 벤치마킹할 때
- 여러 영상의 하이라이트를 이어 붙여 TOP3/TOP5를 만들 때
- TikTok, Douyin, Xiaohongshu, YouTube에서 주제를 조사할 때
- 한국어 TTS, 자막, EDL, FFmpeg 결과물이 함께 필요할 때

## 필수 권리 게이트

1. 플랫폼 영상은 기본적으로 조사 전용으로 취급한다.
2. 사용자 소유, 서면 허가, 호환 라이선스, CC, 퍼블릭 도메인만 편집한다.
3. 재업로드 금지 문구가 있거나 권리가 불명확하면 즉시 제외한다.
4. 출처, 제작자, 라이선스 URL, 확인 날짜를 `source_manifest.json`에 기록한다.
5. 워터마크 제거, Content ID 회피, 속도·좌우반전으로 탐지 회피를 하지 않는다.

## 벤치마크 기본값

- 포맷: 1080x1920, 30fps, H.264/AAC.
- TOP3 권장 길이: 31~38초.
- 항목 길이: 3위 8~10초, 2위 9~11초, 1위 11~14초.
- 첫 2초: 실제 3위 영상 위에서 제목과 훅 시작.
- 항목 구조: 설정 2~3초, 행동 4~6초, 반응 1.5~2.5초, 꼬리 0.5~1초.
- 일반 항목은 7초 미만으로 자르지 않는다.
- 순위가 높아질수록 장면을 조금 더 길게 배치한다.

## 조사 절차

1. 레퍼런스 채널에서 최소 10개의 제목, 날짜, 길이, 조회수, 좋아요,
   댓글 수를 수집한다.
2. 제목의 TOP 숫자로 `길이 / 항목 수`를 계산한다.
3. 300만 조회 이상 표본의 항목당 중앙값을 우선 기준으로 삼는다.
4. 스토리보드나 합법적인 재생 화면에서 순위 색상 변경 시점을 기록한다.
5. 관찰값과 인기 원인에 대한 추론을 분리한다.
6. TikTok Creative Center, Douyin Hot, Xiaohongshu Explore는 주제 조사에만
   사용하고 권리 확인 전에는 소스 목록에 넣지 않는다.

## 대본 규칙

- 한 문장은 8~20자 정도로 짧게 쓴다.
- 영상에 이미 보이는 행동을 장황하게 반복하지 않는다.
- `순위 선언 -> 상황 한 줄 -> 반응 또는 반전 -> 다음 순위` 순서로 쓴다.
- 1위 끝에는 질문형 CTA 하나만 둔다.
- 한국어 원고만 사용하고 일본어 가나가 섞이면 빌드를 중단한다.

예시:

```text
웃음 참기 힘든 귀여운 동물 TOP3.
3위, 미어캣 경호팀. 한 마리가 돌면 둘이 동시에 경계합니다.
2위, 장난감을 발견한 고양이. 모른 척하다 결국 몸이 먼저 반응하죠.
1위, 수달들의 단체 눈치게임. 한 마리가 움직이면 전부 따라갑니다.
여러분의 1위는 몇 번인가요?
```

## 음성 규칙

- 기본 음성: `ko-KR-HyunsuMultilingualNeural`.
- 허용 속도: 0%~+12%. 속도보다 원고를 줄여 타이밍을 맞춘다.
- 각 순위 음성은 해당 순위 종료 0.3초 전에 끝낸다.
- 원본 환경음은 15~25%로 낮추고 TTS가 명료하게 들리게 한다.

## 화면 규칙

- 상단 제목은 전체 영상에 고정한다.
- 좌측 순위표를 고정하고 현재 순위만 초록, 노랑, 빨강으로 강조한다.
- 하단 자막은 1~2줄, 한 줄 16자 안팎으로 제한한다.
- 모바일 UI가 가리는 최하단 180px에는 핵심 문구를 놓지 않는다.
- 컷 전환은 순위 변경 때만 사용하고 항목 내부는 행동을 이어 보인다.

## 출력물

- `benchmark_analysis.md`
- `trend_and_sources.md`
- `source_manifest.json`
- 타임코드가 포함된 대본과 ASS 자막
- 재현 가능한 빌드 스크립트
- 최종 1080x1920 MP4
- 3개 이상의 시점별 QA 이미지

## 검증

```powershell
ffprobe -v error -show_entries format=duration,size -of json output.mp4
ffmpeg -v error -i output.mp4 -f null -
```

추가 확인:

- 영상 길이 31~38초
- 오디오와 비디오 스트림 존재
- 순위별 길이 8초 이상
- TTS 겹침 없음
- 일본어 가나 없음
- 모든 사용 소스의 권리 기록 존재
