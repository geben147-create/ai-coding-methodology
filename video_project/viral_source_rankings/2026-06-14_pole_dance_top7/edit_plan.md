# 폴댄스 TOP7 편집 계획

## 콜드 오픈

- 1번 나선형 폴 장면을 첫 프레임부터 공중 상태로 시작한다.
- 0.0초에 노란색 `폴댄스 기술`, 흰색 `TOP7`, 빨간 현재 순위를 즉시 노출한다.
- 준비 동작보다 기술 완성 장면을 먼저 보여 주고, 설명은 0.25초 뒤 들어간다.

## 선정 순서

1. 나선형 폴 연속 회전
2. 붉은 무대 공중 인버트
3. 높은 위치 다리 확장과 인버트
4. 한 팔 수평 자세 반전
5. 바닥에서 공중으로 이어지는 예술적 전환
6. 연습실에서 우승 무대로 전환
7. 바닥 안무에서 폴 상승으로 마무리

## 다이내믹 리프레이밍

- 1080x1920 세로 캔버스 중앙에 원본을 배치한다.
- 가로 원본은 흐린 풀 프레임 배경 위에 원본 전체를 중앙 정렬한다.
- 모든 컷에 최대 2.5%의 느린 펀치인을 적용해 정지 화면처럼 보이지 않게 한다.
- 세로 원본은 과도하게 확대하지 않고 원래 구도를 우선한다.

## 전환

- 각 8초 경계는 음악과 동작의 방향이 바뀌는 하드 컷으로 연결한다.
- 전환 효과가 기술 완성 프레임을 가리지 않도록 오버랩은 사용하지 않는다.
- 빨간 현재 순위가 바뀌는 순간을 시각적 전환 신호로 사용한다.

## 자막 후보

- 통합본 하단에 한 줄짜리 교육형 설명을 크게 배치한다.
- 자막은 흰색, 핵심 단어는 노란색 제목과 빨간 순위로 분리한다.
- 개별 코어와 핸들 파일에는 자막을 넣지 않는다.

## 원본 오디오

- 개별 파일은 원본 오디오를 유지한다.
- 통합본은 원본 오디오를 약 30%로 낮추고 VoiceBox Sohee를 전면에 둔다.
- 장면의 박수나 반응은 완전히 지우지 않는다.
