# 게시 안전본 교체 계획

현재 사용자는 `게시용 안전본`을 요청하지 않았다. 따라서 Pexels,
Pixabay, 스톡 영상으로 대체하지 않았고, 공개 업로드용 영상도 만들지
않는다.

## 우선 경로

| 후보 | 현재 판정 | 게시 가능 상태로 만드는 방법 |
|---|---|---|
| C02 | permission-required | Unitree에 00:00.0-00:10.5 재편집·수익화·플랫폼 게시 범위를 명시해 서면 허가 요청 |
| C04 | permission-required | Unitree에 00:05.0-00:16.0 사용 허가 요청 |
| C01 | permission-required | Unitree에 00:00.0-00:11.0 사용 허가 요청 |

허가를 받으면 원본 링크, 허가자, 허가일, 허용 플랫폼, 수익화 가능 여부,
편집 가능 범위, 크레딧 문구를 프로젝트에 함께 보관한다.

## 허가를 받지 못한 경우

1. Unitree가 공식 배포한 보도자료·프레스킷에서 영상 재사용 조건을
   확인한다. 단순히 다운로드할 수 있다는 이유로 사용하지 않는다.
2. 동일한 로봇 동작을 직접 촬영하거나, 사용자가 권리를 보유한 3D
   애니메이션으로 재현한다.
3. 사용자가 정확히 `게시용 안전본`이라고 요청한 경우에만 권리 확인된
   스톡 또는 공개 라이선스 소스를 조사한다.

스톡 대체를 실제로 사용한 경우에만 다음 문구를 표시한다:

`원본 바이럴 소스를 못 써서 대체함`
