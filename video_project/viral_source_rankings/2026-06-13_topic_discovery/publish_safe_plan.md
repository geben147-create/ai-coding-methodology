# 게시 안전본 교체 계획

공개 업로드 전 모든 `permission-required` 소스를 권리가 확인된 소스로
교체하거나 원작자의 서면 허가를 확보한다.

스톡 소스는 사용자가 `게시용 안전본`을 명시적으로 요청한 경우에만 사용한다.
현재 비공개 검토본에는 스톡 대체 소스를 사용하지 않았다.

| 후보 | 현재 판정 | 교체 또는 허가 계획 |
|---|---|---|
| C02 | 허가 필요 | Unitree Robotics의 서면 허가 또는 직접 촬영한 훈련 장면 |
| C04 | 허가 필요 | Unitree Robotics의 서면 허가 또는 권리 확인된 균형 회복 장면 |
| C01 | 허가 필요 | Unitree Robotics의 서면 허가 또는 직접 제작한 바퀴형 로봇 장면 |

공개 게시용으로 전환할 때도 랭킹 구조, 한국어 대본, 자막 리듬은 유지할 수
있지만 현재 원본 영상과 원본 오디오는 그대로 사용할 수 없다.
