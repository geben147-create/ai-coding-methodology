# 스킬 패치 요약

## 추가

- `scripts/analyze_channel_style.py`: 롤링 VTT 중복 제거와 파생 스타일 계량.
- `scripts/test_analyze_channel_style.py`: 원문 미노출과 조회수 정렬 테스트.
- `references/channel-style-benchmark.md`: 채널 스타일 분석의 저작권·정체성 경계.
- `SKILL.md`: 원문 코퍼스 복제, 사칭, 무단 음성 복제, 탐지 회피 금지.

## 유지

- private-review와 publish-safe 권리 경계.
- 워터마크·출처 유지.
- 선택 우선, 7~9초 코어, 1초 핸들.
- 다중 YouTube 검색과 역검색 프레임.

기존 조항은 삭제하지 않았다.
