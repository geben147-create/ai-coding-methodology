# 볼링 TOP7 편집 계획

## 콜드 오픈

290만 회 C05의 장거리 굴리기를 첫 장면으로 사용해 1초 안에 불가능해 보이는 조건을 제시한다.

## 선정 순서

C05, C06, C07, C11, C12, C23, C25 순이며 검증된 조회수 내림차순이다.

## 다이내믹 리프레이밍

원본 전체를 중앙에 유지하고 블러 배경과 1.00~1.065의 완만한 확대만 사용한다.

## 자막 후보

상단 `전설의 볼링 기술;;`, 보조 `조회수 TOP7`, 중앙에는 장면별 새 분석 문장을 사용한다.

## 채널 벤치마크 적용

- 트릭볼러 12개 Shorts 중앙 길이 34.5초, 중앙 발화 밀도 6.43글자/초를 참고했다.
- 제목은 `전설의 볼링 기술;;`처럼 구체 행동과 고강도 단어를 결합했다.
- 문장은 설명형 존댓말과 `인데요` 전환을 사용하되 원문 표현은 복제하지 않았다.
- 49초 TOP7로 확장했으며 각 항목은 7초다.

## 화면

- 1080×1920, 30fps, 원본 전체를 블러 배경 위 중앙 배치.
- 순위 1→7을 조회수 내림차순으로 표시.
- C06과 C23의 작은 핀 구간에만 빨간 포커스 박스 적용.
- 워터마크·로고·원본 자막은 가리지 않음.
- 뒤집기, 속도 변경, VFR, 회전, 탐지 회피용 오프셋은 미사용.

## 오디오

- 내장 Sohee 프리셋의 새 한국어 분석 대사 사용.
- 크리에이터 음성 복제 미사용.
- 원본 오디오는 약 22%로 남겨 현장 맥락 보존.
- 외부 BGM/SFX 미사용.
