# 오디오 계획

## 원본 대화

일곱 장면의 원본 대화, 웃음, 놀람과 생활 소리를 우선 보존한다. 추가 TTS는
사용하지 않는다. C07은 1080p 영상 스트림과 같은 게시물의 AAC 오디오 스트림을
타임코드 기준으로 재결합한다.

## 효과음

별도 외부 효과음은 넣지 않는다. 원본의 웃음과 놀람을 효과음처럼 살리고,
시각 플래시와 자막 팝만 사용한다. 라이선스가 불명확한 효과음을 억지로 추가하지
않는다.
