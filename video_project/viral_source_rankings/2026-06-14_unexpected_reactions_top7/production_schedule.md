# 제작 스케줄

| 단계 | 상태 | 산출물 |
|---|---|---|
| 후보 조사 20개 이상 | 완료 | `source_candidates.md` |
| 최초 게시 추적 | 완료 | `source_trace.md` |
| YouTube 중복 검색 | 완료 | `youtube_duplicate_report.md` |
| TOP7 선정과 초 구간 확정 | 완료 | `selection_manifest.md`, `cut_manifest.json` |
| 사용자 비공개 검토 승인 | 완료 | `cut_manifest.json` approval |
| Studio 배경음 확보 | 완료 | `audio/`, `audio_plan.md` |
| 8초 코어와 10초 핸들 렌더 | 완료 | `selects/` |
| 56초 통합 MP4와 SRT | 완료 | `combined/`, `captions/` |
| CapCut 폴더 구성 | 완료 | `capcut_project/` |
| QA와 계약 검증 | 완료 | `qa/`, validator output |

공개 업로드 단계는 이 일정에 포함하지 않는다.
