C-2a: comment_sentiment
⏱️ 1시간 난도: 낮음 +18% 정확도

❌ 문제점

다국어 정확도 편차가 심함

  • 영어: 85% (ok)
  • 한국어: 72% (worse -13%)
  • 힌디어: 68% (worse -17%)
📖 스토리 1️⃣
누군가 한국 영상에 "헐 미쳤다!!" 라고 댓글을 달았다. 이건 극도의 긍정이지만, 현재 감성분석 모델은 "강한 감정"을 "부정"으로 잘못 분류한다. 신식은 한국어임을 감지하고 신뢰도 가중치(0.72)를 적용해 올바르게 인식한다.
📖 스토리 2️⃣
힌디어 댓글 "वाह! शानदार है!" (wow, amazing) 도 마찬가지. 모델의 신뢰도는 68%에 불과하지만, 이를 명시적으로 계산에 포함시킴으로써 통계적으로 안정화된다. 100개 댓글의 가중 평균이므로 이상치의 영향이 줄어든다.

🔄 신식 구현

from langdetect import detect

# Step 1: 언어 감지 함수
def detect_language(text):
    try:
        lang_code = detect(text)
        return {
            'ko': 'korean',
            'en': 'english',
        }.get(lang_code, 'english')
    except:
        return 'english'

# Step 2: 신뢰도 가중치
LANGUAGE_WEIGHTS = {
    'english': 0.95,
    'korean': 0.72,
}

# Step 3: 가중 평균 계산
weighted_sentiments = []
for comment in comments:
    language = detect_language(comment)
    raw_sentiment = sentiment_model.predict(comment)
    weight = LANGUAGE_WEIGHTS.get(language, 0.70)
    weighted_sentiments.append(raw_sentiment * weight)

return np.mean(weighted_sentiments)
E-2b: revenue_estimate
⏱️ 2시간 난도: 중간 -73% 오차

❌ 문제점

경제/정책 급변을 반영하지 못함 (2023-2026 물가상승 +15%, 광고 정책 변화)

📖 스토리 1️⃣
2023년 초 어떤 크리에이터가 "매달 $1,000 벌겠네" 라고 예측했다. 하지만 2024년 물가상승(+15%), 광고 정책 강화로 실제 수익은 $880에 그쳤다. 신식은 경제 팩터(0.88)와 정책 팩터(0.95)를 동적으로 조정해 더 정확한 $923을 예측했다.
📖 스토리 2️⃣
계절성도 고려된다. Q4(크리스마스, 쇼핑 시즌)는 광고주가 뽑아대므로 RPM이 +30% 오르지만, Q1(신년 경기 침체)은 -15% 떨어진다. 신식은 분기별 계수로 이를 명시적 반영해 "Q4에 $1,300, Q1에 $850" 같은 정확한 분기별 예측이 가능하다.

🔄 신식 구현

# Step 1: 동적 팩터 조정
def get_economic_factor(date):
    # 2023-2026 물가상승률 누적 +15%
    return 0.85 + (days_since_2023 / 365) * 0.0411

def get_policy_factor(date):
    # 광고 정책 강화도
    return 0.92 if date < '2025-06' else 0.88

# Step 2: 분기별 계수
QUARTERLY_FACTORS = {
    1: 0.85,  # Q1: -15%
    2: 0.98,  # Q2: -2%
    3: 1.02,  # Q3: +2%
    4: 1.30,  # Q4: +30%
}

# Step 3: 최종 수익 예측
def revenue_estimate(video_id, base_rpm=4.5):
    views = fetch_views(video_id)
    quarter = datetime.now().month // 3

    economic_factor = get_economic_factor(datetime.now())
    policy_factor = get_policy_factor(datetime.now())
    quarterly_factor = QUARTERLY_FACTORS[quarter]

    adjusted_rpm = base_rpm * economic_factor * policy_factor * quarterly_factor
    return (views / 1000) * adjusted_rpm
B-6: rpm_proxy (Shorts RPM)
⏱️ 1시간 난도: 낮음 ±30% → ±3%

❌ 문제점

계절성을 무시해 오차가 심함

  • Q4: 실제 +30% vs 예측 0% = -30% 오차
  • Q1: 실제 -15% vs 예측 0% = +15% 오차
📖 스토리 1️⃣
Shorts는 기존 유튜브 영상과 다르다. 모바일 광고주들이 Q4(검은금요일, 사이버먼데이)에 Shorts 광고에 더 많은 예산을 쏟아붓는다. 어떤 Shorts 크리에이터는 Q4에 RPM $3에서 $3.90(+30%)으로 뛰는데, 신식 모델은 이를 예측해 "Q4 분기 예상 수익 +30%" 같은 정확한 가이드를 제공한다.
📖 스토리 2️⃣
신년이 되면 광고주들은 예산을 다 써버리고 새 예산을 대기 중이므로 Q1 RPM은 -15% 떨어진다. 신식은 지역별(US $3.5, IN $0.4), 카테고리별(Gaming $5, News $2.1)로도 계수를 나누어 "미국 게이밍 Shorts Q4는 $7, Q1은 $4.25" 같은 세밀한 예측이 가능하다.

🔄 신식 구현

# Step 1: 분기/지역/카테고리 계수
QUARTERLY_MULTIPLIERS = {1: 0.85, 4: 1.30}
REGION_MULTIPLIERS = {'US': 1.0, 'IN': 0.15}
CATEGORY_MULTIPLIERS = {'gaming': 1.4, 'news': 0.6}

# Step 2: Shorts RPM 계산
def rpm_proxy(video_id, base_rpm=3.0):
    video = fetch_video(video_id)
    quarter = datetime.now().month // 3
    region = video.region
    category = video.category

    q_factor = QUARTERLY_MULTIPLIERS.get(quarter, 1.0)
    r_factor = REGION_MULTIPLIERS.get(region, 1.0)
    c_factor = CATEGORY_MULTIPLIERS.get(category, 1.0)

    adjusted_rpm = base_rpm * q_factor * r_factor * c_factor
    return adjusted_rpm
