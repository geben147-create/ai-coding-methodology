① 요구사항 단계
Superpowers — /brainstorm

프롬프트 1 — 기능 설계 전
/brainstorm 유저 알림 기능을 추가하려고 해. 누가 쓸 건지, 성공 기준이 뭔지, 어떤 문제를 해결하는지 질문으로 정리해줘.
프롬프트 2 — 요구사항 불명확할 때
/brainstorm 대시보드 필터 기능 추가. 요구사항이 명확하지 않아. 어떤 질문들을 먼저 정리해야 할지 뽑아줘.
프롬프트 3 — MVP 범위 결정
/brainstorm MVP 결제 플로우 설계 전, 핵심 고려사항과 가장 좁은 진입점이 어딘지 질문 형식으로 뽑아줘.

③ 구현 단계
Superpowers — /sdd
큰 기능을 서브 에이전트로 분업. 컨텍스트 오염 없이 2시간 이상 유지.
프롬프트 1 — 인증 시스템
/sdd 인증 시스템 구현. JWT 발급, 미들웨어, 리프레시 토큰 3개 파트로 나눠서 서브 에이전트 분업해줘.
프롬프트 2 — 쇼핑카트
/sdd 쇼핑카트 기능 전체. 상태관리, API 연동, UI 컴포넌트 분리해서 각 서브 에이전트가 맡아줘.
프롬프트 3 — 파일 업로드
/sdd 대용량 파일 업로드 기능. 청크 분할, 진행상태 표시, 에러 핸들링 3파트로 나눠줘.

/office 개발자용 시간 추적 SaaS 만들려고 해. 진짜 수요 있는지 YC 스타일로 핵심 질문 6개 던져줘.
프롬프트 2 — 콘텐츠 기획
/office 이 영상 기획: AI 코딩 도구 비교. 진짜 필요로 하는 사람이 누구인지, 가장 좁은 진입점 어딘지 뽑아줘.
프롬프트 3 — 사이드 프로젝트
/office 프리랜서 계약서 자동 생성 서비스. 기존에 어떻게 해결하고 있는지, 내 진입점 어딘지 날카롭게 만들어줘.

/browse 내 랜딩페이지 열고 CTA 버튼 클릭 → 폼 제출까지 전체 플로우 단계별로 스크린샷 찍어줘.
프롬프트 3 — 모바일 QA
/browse 모바일 뷰포트 375px로 내 사이트 열고 레이아웃 깨지는 부분 찾아서 스크린샷으로 보고해줘.
